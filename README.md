# 🍗 Chicken Mashwi

> **Good Food, Good Mood • The Taste of Real Arabia**  
> Authentic charcoal-grilled rotisserie chicken in Lahore.

---

## 📖 About
Chicken Mashwi specializes in authentic Arabic slow flame roasted chicken marinated in traditional spices like sumac, smoked paprika, and cumin, served with fluffy yellow & white Bukhari rice, crispy fried onions, potato wedges, fresh tomato and daqoos sauces.

## 🚀 Features
- **Modern & GenZ Interactive UI:** Spatial layout with glassmorphism, warm Arabian color palette, and animated chicken mascots.
- **Alternating Themed Sections:** Dynamic alternating background sequence (Yellow ↔ White).
- **Responsive Navigation:** Fluid floating pill navbar with mobile drawer, touch-friendly tap targets, and outside-click dismiss.
- **Dynamic Online Cart:** Add items to cart with live price calculations and a seamless slide-out cart sidebar.
- **WhatsApp Direct Checkout:** Form to capture customer name, phone, address, and special notes with 1-click WhatsApp order generation.
- **Official Standalone Menu Cards (`menu.html`):** High-resolution scans with interactive zoom.
- **Performance Optimized:** 80% compressed assets (~39 MB total payload down from 192 MB) with lazy loading and 60–120 FPS GPU-accelerated motion.

## 💻 Local Setup & Running
To run Chicken Mashwi locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/asadchaudhary27/chickenmashwi.git
   cd chickenmashwi
   ```

2. **Launch the server:**
   - Double-click **`start.bat`** (or **`run.bat`**)
   - Or run with Node.js directly:
     ```bash
     node server.js
     ```

3. **Open in browser:**
   ```
   http://localhost:3000
   ```
